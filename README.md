# AI-Engineer-Challenges

A collection of real world AI Engineering projects, technical assessments, and production-oriented implementations.

This repository demonstrates practical experience in designing, building, and deploying AI-powered systems across multiple domains, including LLM applications, AI Agents, Retrieval-Augmented Generation (RAG), OCR, IoT analytics, workflow automation, and full-stack development.

## Projects

### Assessment 1: AI Agent Workflow Automation. [Demo Video](https://www.loom.com/share/42c4f3ceb0c24e4691cda3c5ced993b6)
Build intelligent AI agents capable of automating business workflows, tool calling, and orchestration.

### Assessment 2: IoT Sensor Data Trend Prediction. [Demo Video](https://www.loom.com/share/e675bc7f404d4fbba634d6e5606a306e)
Develop machine learning models to analyze sensor data and predict future trends.

### Assessment 3: Local OCR & Dynamic RAG System. [Demo Video](https://www.loom.com/share/d57d326eee76450183557ea90b5e1776)
Create a fully local document processing pipeline combining OCR with Retrieval-Augmented Generation for intelligent document search and question answering.

### Assessment 4: Full-Stack Service Marketplace. [Demo Video](https://www.loom.com/share/52a6caa58f59450dafb4a3876570d943)
Build a modern full-stack marketplace integrating AI capabilities with scalable backend services and responsive frontend design.
